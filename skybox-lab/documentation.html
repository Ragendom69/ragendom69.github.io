🌐 SkyboxLab Documentation

Generate AI-powered 360° skyboxes from text prompts, directly inside the Unity Editor.

Overview

SkyboxLab is a Unity Editor plugin that connects to the SkyboxLab cloud backend to generate high-quality, AI-generated 360° panoramic skyboxes from simple text descriptions. Type a prompt, click generate, and a production-ready equirectangular skybox is downloaded, imported with correct texture settings, turned into a Skybox/Panoramic material, and optionally applied to your scene — all without ever leaving Unity.

Pricing & API Key

Account & API Key Required

This Unity asset is completely free to download and install. However, generating skyboxes requires a SkyboxLab account and a valid API key. The generation runs on SkyboxLab's cloud GPU infrastructure, which is why an account is needed.

How to get your API key

  1. Create a free account at the SkyboxLab dashboard. You can reach it by clicking the "Get API Key" button next to the API Key field inside the Unity plugin, or by navigating to your server URL + /dashboard in a web browser.
  2. Verify your email. After registering, you will receive a verification email. Click the confirmation link before proceeding — you will not be able to access the dashboard until your email is verified. Check your spam folder if you don't see it within a few minutes.
  3. Start with your free welcome generations. Every new account receives 5 free skybox generations so you can test the plugin and see the quality before purchasing credits.
  4. Copy your API key from the dashboard Settings page. Keys start with the prefix skb_.
  5. Paste it into the API Key field in the SkyboxLab Editor window and click Test Connection.
After the 5 Free Generations

Once your 5 free welcome generations are used up, you will need to purchase credits to continue generating skyboxes. You can top up credits directly from the SkyboxLab dashboard. The plugin displays your remaining free generations and credit balance in the connection section so you always know where you stand.

Installation

  1. Import the asset into your Unity project via the Asset Store or by dragging the .unitypackage file into your Project window. All files live under Assets/SkyboxLab/ and will not modify any existing project files.
  2. Wait for compilation. Unity will automatically compile the editor scripts. If you see no errors in the Console, you are ready to go.
  3. Open the plugin via the menu: Window → SkyboxLab → Skybox Generator.
No Dependencies

SkyboxLab has zero external dependencies. It uses only built-in Unity APIs (UnityWebRequest, EditorWindow, TextureImporter, AssetDatabase) and the built-in Skybox/Panoramic shader. No packages to install, no assembly definitions to configure.

Quick Start

  1. Open Window → SkyboxLab → Skybox Generator.
  2. The Server URL is pre-filled. Paste your API Key (starts with skb_).
  3. Click Test Connection — you should see a green ✓ Connected, your usage quota, and your credit balance.
  4. Type a prompt, for example: "Vast savanna at golden hour, acacia trees, dramatic orange sky"
  5. Optionally pick a Style preset (e.g. Photoreal, Anime, Fantasy).
  6. Click ⚡ GENERATE SKYBOX and wait ~30–60 seconds (or ~60–90 seconds with seam fix + upscale).
  7. Done! The skybox is saved to Assets/SkyboxLab/Generated/ and (if enabled) automatically applied to your scene.

Editor Window

The SkyboxLab Editor window is your single control panel for everything. Open it via Window → SkyboxLab → Skybox Generator. The window is resizable and is divided into the following sections from top to bottom:

  • Connection — Server URL, API Key, connection test, usage quota, credit balance, and Top Up button
  • Prompt — Main text prompt input area
  • Style — Collapsible style preset picker (12 presets)
  • Negative Prompt — Collapsible field for things to avoid in the generation
  • Options — Quality (with optional 4× upscale), diffusion steps, and CFG guidance controls
  • Import Settings — Auto-apply skybox and ambient lighting update toggles
  • Generate — The generate button (with live cost estimate), progress bar, and cancel button
  • Recent Skyboxes — Thumbnail gallery of all previously generated skyboxes

All settings are persisted between Unity sessions via EditorPrefs.

API Key Locks After First Connection

When you click Test Connection and the server responds with ✓ Connected, your API key is locked to this Unity installation. The editable password field is replaced with a read-only masked display (🔒 skb_XXXX••••••) and cannot be changed through the plugin UI.

This is by design — it prevents accidental key changes and unauthorized key swapping.

If you need to reset your API key (e.g. you entered the wrong key, or you are migrating to a new account), you must perform both of these steps:

  1. Delete the file {YourProject}/Library/SkyboxLab.lock
  2. In Unity, open Edit → Preferences and remove the EditorPrefs key SLB_lk_v1 (you can use a script or the EditorPrefs section of a prefs editor asset)

After both steps, reopen the SkyboxLab window — the API Key field will be editable again. The Library/ folder is excluded from version control by default, so the lock does not travel with your project if you share it via Git.

Prompt Guide

The prompt is the most important factor in the quality of your skybox. Here are some tips:

What works well

  • Open outdoor landscapes with visible sky and horizon
  • Descriptive lighting conditions (golden hour, overcast, night, etc.)
  • Atmospheric details (fog, clouds, aurora, stars)
  • Specifying a mood or time of day

Example prompts

PromptGood for
"Vast savanna at golden hour, acacia trees, dramatic orange sky"Warm outdoor scene
"Arctic tundra at night, blazing aurora borealis, frozen lake"Night / sci-fi scene
"Ancient temple ruins in jungle clearing, shafts of golden light"Adventure / RPG scene
"Volcanic island at dusk, lava flows, fiery red sky"Dramatic action scene
"Calm ocean at sunrise, pastel pink and blue sky, gentle waves"Relaxing / casual game
"Deep space nebula, swirling purple and blue gas clouds, distant stars"Sci-fi / space game

What to avoid

  • Fully enclosed spaces (caves, room interiors) — skyboxes are meant to be open environments
  • Very specific complex objects (a particular car model, a named character)
  • Extremely long prompts — keep it focused on the scene description

Negative prompt

The negative prompt tells the AI what to avoid. A sensible default is pre-filled: 

blurry, distorted, watermark, text, logo, seam, people, faces, hands,
low quality, jpeg artifacts, overexposed, underexposed, ugly, deformed

You can expand the negative prompt section to customise it for each generation.

Style Presets

Style presets add extra keywords to your prompt automatically, guiding the AI toward a specific visual style. Select one from the collapsible style picker below the prompt field. Only one style can be active at a time; clicking the active style again deselects it. Your typed prompt is never modified — the style keywords are appended only when the generation request is sent.

Styles work best when your prompt complements them. For example, pairing Cyberpunk with "Rain-soaked neon cityscape at midnight" reinforces the style, while pairing it with "Peaceful countryside meadow" creates a conflicting mix. Match your prompt to the style for best results.

Generation Options

OptionValuesDescription

Adds $0.02 to the generation cost. Takes longer but produces significantly sharper results. Recommended for production use and VR.
Steps 20 (fast)
28 (default)
40 (quality) 		Number of diffusion sampling steps. More steps produce more detail and coherence but take longer. 28 is a good balance of quality and speed for most prompts. Use 40 for complex scenes where fine detail matters.
Guidance 1.0 – 15.0 (default 7.5) CFG (Classifier-Free Guidance) scale — controls how closely the AI follows your prompt. Higher values = more literal interpretation but can look oversaturated. Lower values = more creative freedom but may drift from your description. 7.5 works well for most prompts. Does not affect cost.

Live Cost Display

Credits & Balance

SkyboxLab uses a prepaid credit system. Your current balance is displayed in the Connection section of the editor window:

  • Green balance — healthy, you have enough credits to generate
  • Red balance — low (below $0.14), you may not have enough for the next generation

After each successful generation, the estimated cost is deducted from your displayed balance immediately. The balance is then refreshed from the server to show the authoritative amount.

You can click the + Top Up button at any time to open the dashboard and add credits to your account.

Architecture

The plugin is composed of three editor-only C# scripts:

ScriptTypeResponsibility
SkyboxLabWindow.cs EditorWindow The main UI. Draws all controls, manages state, persists settings via EditorPrefs, orchestrates the generate → poll → import flow, and displays the gallery.
SkyboxLabAPI.cs static class HTTP client. Handles POST /api/generate, polling GET /api/generate/status/{id}, connection testing, and usage fetching. Uses EditorApplication.update for async polling (no coroutines, no threads).
SkyboxLabImporter.cs static class Downloads the PNG via UnityWebRequestTexture, saves it to disk, configures TextureImporter settings, creates a Skybox/Panoramic material, and optionally applies it to the scene.
Editor-Only — Zero Runtime Overhead

All scripts are inside an Editor/ folder, which means they are never included in your game build. The plugin has zero runtime overhead and zero impact on your shipped game's size or performance.

API Reference

The plugin communicates with the SkyboxLab backend via these HTTP endpoints. Authentication is via the X-API-Key header on every request.

GET /health

Connection test. Returns { "status": "ok" }. Timeout: 8 seconds.

GET /api/user/usage

Returns quota information for the authenticated user.

{
  "used": 42,
  "limit": 100,        // null if unlimited
  "unlimited": false,
  "remaining": 58,     // null if unlimited
  "tier": "starter"
}

GET /api/payments/credits

Returns the user's credit balance and remaining welcome generations (if any).

{
  "balance": 4.73,
  "balance_cents": 473,
  "formatted": "$4.73"
}

POST /api/generate

Submits a generation job. Returns immediately; the job runs asynchronously on the server.

// Request body:
{
  "prompt": "Ancient ruins at golden hour...",
  "negative_prompt": "blurry, distorted...",
  "steps": 28,
  "guidance": 7.5,
  "upscale": true
}

// Response:
{
  "job_id": "abc123",
  "status": "pending"
}

GET /api/generate/status/{job_id}

Polled every 3 seconds until the job completes or fails. Maximum 200 attempts (~10 minutes).

{
  "id": "abc123",
  "status": "succeeded",      // "pending" | "processing" | "succeeded" | "failed"
  "output_url": "https://...",// URL to the generated PNG (when succeeded)
  "error": null               // error message (when failed)
}

Texture Import Settings

The importer configures the downloaded PNG with these exact TextureImporter settings to ensure optimal quality for panoramic skybox use:

SettingValueReason
textureTypeDefaultStandard 2D texture
npotScaleNoneKeep original 2:1 aspect ratio (1440×720 or 8192×4096 with upscale)
mipmapEnabledfalsePrevents visible seam line on the skybox sphere
wrapModeRepeatSeamless horizontal wrapping for 360° panorama
filterModeBilinearSmooth filtering without excessive blur
maxTextureSize8192Allows full resolution import without downscaling
textureCompressionUncompressedMaximum quality, no compression artifacts
Do Not Re-Import Manually

If you manually re-import a generated texture, make sure to keep Generate Mip Maps unchecked and Wrap Mode set to Repeat. Changing these settings will cause visible seam lines on the skybox sphere.

HDRP Projects

HDRP Requires Manual Setup

In HDRP, RenderSettings.skybox is not used for rendering. The auto-apply feature will still set it, but it won't be visible in HDRP scenes. Instead, follow these steps:

  1. Generate and import the skybox normally using SkyboxLab.
  2. In your scene's Volume, add a Visual Environment override and set Sky Type to HDRI Sky.
  3. Add an HDRI Sky override and assign the generated PNG texture to the HDRI Sky texture slot.

The texture import settings applied by SkyboxLab (no mipmaps, repeat wrap, uncompressed, 8192 max size) are fully compatible with HDRP's HDRI Sky component.

URP Works Out of the Box

If you are using URP (Universal Render Pipeline), the auto-apply feature works as expected. No extra setup needed.

Troubleshooting

"Test Connection" shows ✗ Failed

  • Check that the Server URL is correct and reachable from your network.
  • Ensure you have an active internet connection.
  • If using a firewall or VPN, make sure outbound HTTPS traffic is allowed.

"Generation failed" error

  • quota exceeded — your 5 free welcome generations are used up and your credit balance is zero. Visit the SkyboxLab dashboard to top up credits.
  • invalid API key — your key may have been revoked or is malformed. Generate a new key from the dashboard. If your key is locked, see the API Key Lock section for reset instructions.
  • Any other error — check the Unity Console for the full [SkyboxLab] log line and include it when contacting support.

Generation times out after 10 minutes

  • The backend may be under heavy load. Try again in a few minutes.
  • Check your network connection — the plugin needs to reach the server every 3 seconds for status polling.

Skybox has a visible seam line

  • SkyboxLab's pipeline automatically applies a circular-shift seam fix with AI inpainting to eliminate the vertical seam. If you still see a faint line, check the following:
  • Verify that the texture's Generate Mip Maps is unchecked in the Inspector. The importer does this automatically, but if you re-imported manually, double-check this setting.
  • Ensure Wrap Mode is set to Repeat.

Skybox looks low-resolution

  • The native output is 1440×720px. For much sharper results, enable the 8K Texture toggle, which upscales to 8192×4096px.
  • Check the texture's Max Size in the Inspector — it should be 8192.
  • Ensure Compression is set to None (Uncompressed).

Skybox not visible in HDRP

  • See the HDRP section above. You need to manually assign the texture to an HDRI Sky volume override.

Compilation errors after import

  • Ensure all three .cs files are inside the Editor/ folder.
  • If you see namespace errors, confirm you are on Unity 2020.3 LTS or newer.

Cannot edit the API Key field

  • Your key has been locked after a successful connection. This is intentional. See API Key Lock for reset instructions.

Frequently Asked Questions

Does this plugin affect my game's build size or runtime performance?

No. All plugin scripts are in an Editor/ folder and are excluded from builds automatically. The generated PNG textures and materials are included in your build (like any other asset), but the plugin code itself has zero runtime footprint.

Can I use the generated skyboxes commercially?

Yes. Skyboxes generated through SkyboxLab are yours to use in any project, commercial or otherwise. Refer to the SkyboxLab terms of service on the dashboard for full details.

Can I use this plugin offline?

The plugin requires an internet connection to generate new skyboxes, as the AI rendering happens on cloud GPUs. However, previously generated skyboxes (saved in Assets/SkyboxLab/Generated/) are standard Unity assets and work fully offline.

How large are the generated textures?

Native output is 1440×720 pixels. With the 8K Texture option enabled (the default), the output is upscaled to 8192×4096 pixels. File sizes are typically 2–20 MB per PNG depending on the resolution and scene complexity.

Can I use this with Addressables or Asset Bundles?

Yes. The generated PNG textures and materials are standard Unity assets. You can include them in Addressable groups or Asset Bundles like any other texture or material.

What happens if I delete a generated skybox file?

It will be removed from the gallery on the next window refresh. There is no way to recover it through the plugin — you would need to generate a new one with the same (or similar) prompt.
